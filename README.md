# Simple Interest Calculator

## Description
This project is a simple interest calculator that calculates interest based on the principal amount, annual rate of interest, and time period.

## Formula
Simple Interest = (Principal × Rate × Time) / 100

## Inputs
- Principal amount
- Annual rate of interest (percentage)
- Time period (in years)

## Output
- Calculated simple interest
- Total amount (Principal + Simple Interest)

## Example
Principal = 1000  
Rate = 5% per year  
Time = 2 years  

Simple Interest = (1000 × 5 × 2) / 100 = 100  
Total Amount = 1000 + 100 = 1100

## Purpose
This project demonstrates basic arithmetic calculations and user input handling.
